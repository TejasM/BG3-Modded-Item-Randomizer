MIR — Modded Item Randomizer, v1.0.1 — first public release.

Seeds the modded equipment already in your load order into treasure containers, wardrobes, bookshelves, clutter and corpses as you loot them. Strictly additive: never removes, replaces, moves or reprices anything.

**Requires** BG3 Script Extender (v29+) and Mod Configuration Menu (Nexus 9162), loaded above MIR. MIR disables itself if MCM is absent.
